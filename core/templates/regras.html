Como funciona a pontuação?

Entenda como seus palpites viram pontos no ranking.

📋 Pontuação Base (Exemplo: O placar real foi Brasil 3 x 1 México)
Tipo de Acerto Regra Exemplo de Palpite Pontos
Placar Exato (Na mosca) Acerta o vencedor e os gols exatos de ambas as seleções. Brasil 3 x 1 México 5
Vencedor + Saldo Acerta o vencedor e a diferença de gols, mas erra o placar. Brasil 2 x 0 México (Saldo +2) 3
Empate Acerta o empate, mas erra os gols (se o jogo real fosse empate). Brasil 0 x 0 México (se real fosse 1x1) 2
Vencedor + Gols de 1 Time Acerta o vencedor E os gols exatos de apenas um dos times. Brasil 3 x 0 México (Acertou os 3 do Brasil) 2
Vencedor Simples Acerta apenas quem ganhou, errando o saldo e os gols. Brasil 1 x 0 México 1
Erro Total Aposta no perdedor ou aposta em empate havendo vencedor. Brasil 1 x 2 México 0
